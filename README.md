🚀 **欢迎来到 Brainpy-CN！**  

### 🌟 **项目内容**  
Brainpy-CN 是基于 [BrainPy](https://github.com/PKU-NIP-Lab/BrainPy) 搭建的几种经典模型的开源实现

---

### 🧠 **模型类型**  
Hodgkin-Huxley (HH)、连续吸引子神经网络 (CANN)、突触可塑性模型、工作记忆 (WM)   


### 🛠️ **快速环境指南**  
```bash
# 需要Python 3.8
pip install brainpy 
```
